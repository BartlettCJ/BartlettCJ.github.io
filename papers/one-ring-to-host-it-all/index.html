One Ring to Host It All: Fixed-Capacity Circular Realizations of Finite Functional Trajectories

Chris Bartlett · ORCID 0009-0001-3323-0131

Working paper, version 1.32, 29 October 2026.

Motivated by Something is happening: Occurrence Theory. The Zenodo record also holds the archive: the LaTeX source and figures, and the verification code (MIT licence).

Abstract

Can a finite system repeating on a single cycle reproduce, for a specified duration, the behaviour of another deterministic system, even when the visible behaviour appears irreversible?

We formulate this as a circular-sequence problem. Each visible state has a prescribed number of underlying occurrences, and at least a specified number must begin trajectories that follow the visible rule correctly for a given duration. These trajectories may overlap, but every underlying state must belong to one cycle.

We establish necessary and sufficient conditions for such a realisation and give a constructive method based on a compact integer certificate. We then show that existence can be decided in time polynomial in the binary size of the input, using at most n minimum-cost-flow computations for n visible states, without expanding the potentially enormous underlying cycle.

The result provides an exact resource-feasibility criterion for finite-duration effective dynamics within a recurrent reversible host. It establishes mathematical feasibility under specified conditions, without assuming that the required structures arise naturally.
