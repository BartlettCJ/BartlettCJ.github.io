すべてを宿す一つの輪

有限な関数軌道の固定容量円環実現

English title: One Ring to Host It All: Fixed-Capacity Circular Realizations of Finite Functional Trajectories

Chris Bartlett · ORCID 0009-0001-3323-0131

Working paper, version 1.32. Translation published 2 November 2026.

Motivated by Something is happening: Occurrence Theory. The Zenodo record also holds the archive: the LaTeX source and figures, and the verification code (MIT licence).

Abstract

単一のサイクルを繰り返す有限系は、可視挙動が不可逆に見える場合にも、指定された期間にわたって、別の決定論的な系の挙動を再現できるだろうか。

これを巡回列の問題として定式化する。各可視状態には、根底の出現数が指定されており、そのうち少なくとも指定数は、与えられた期間にわたり可視規則に正しく従う軌道の始まりでなければならない。これらの軌道は重なり合ってもよいが、根底のすべての状態が一つのサイクルに属さなければならない。

そのような実現の必要十分条件を確立し、コンパクトな整数証明書に基づく構成法を与える。さらに、潜在的に巨大な根底のサイクルを展開することなく、n個の可視状態について高々n回の最小費用流計算を用いて、存在を入力の2進サイズに関して多項式時間で決定できることを示す。

この結果は、回帰的で可逆なホストの内部の有限期間の実効的力学について、厳密な資源実行可能性の基準を与える。必要な構造が自然に生じると仮定することなく、指定された条件のもとでの数学的な実行可能性を確立する。
