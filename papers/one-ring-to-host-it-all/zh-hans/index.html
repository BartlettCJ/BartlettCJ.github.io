一圈承载一切

有限函数轨迹的固定容量圆周实现

English title: One Ring to Host It All: Fixed-Capacity Circular Realizations of Finite Functional Trajectories

Chris Bartlett · ORCID 0009-0001-3323-0131

Working paper, version 1.32. Translation published 2 November 2026.

Motivated by Something is happening: Occurrence Theory. The Zenodo record also holds the archive: the LaTeX source and figures, and the verification code (MIT licence).

Abstract

一个沿单个循环重复的有限系统,能否在规定的持续时间内再现另一个确定性系统的行为,即使可见行为显得不可逆?

我们将其表述为循环序列问题。每个可见状态具有规定的底层出现次数,其中至少规定数量必须是轨迹的开端,这些轨迹在给定持续时间内正确遵循可见规则。这些轨迹可以重叠,但每个底层状态必须属于同一个循环。

我们确立此类实现的充分必要条件,并给出基于紧凑整数证书的构造方法。随后证明,对于n个可见状态,至多进行n次最小费用流计算,即可在关于输入二进制规模的多项式时间内判定存在性,而无需展开可能极其庞大的底层循环。

结果为重现的可逆宿主内部、有限持续时间的有效动力学提供精确的资源可行性判据。它确立规定条件下的数学可行性,而不假定所需结构会自然产生。
