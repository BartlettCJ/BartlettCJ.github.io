# bartlettcj.github.io

Source of Chris Bartlett's website: papers, essays and books on artificial intelligence, science and
medicine, and translation.

Every page is generated by `_build/build.py` from the record data in `_build/datacite_meta.json`
(fetched from DataCite, the registry behind the papers' DOIs). Edit the content list in `build.py`,
run it, and commit the result. Folders whose names start with `_` are not published.

The papers themselves are archived on Zenodo with permanent DOIs; the copies here are identical
files kept under stable names.
